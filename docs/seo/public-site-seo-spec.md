# Respio public-site SEO specification

## Principles

One dominant intent per page. Product truth outranks keywords. No doorways/thin pages. No production-ready marketplace claim without implementation/runtime proof. Native Russian, useful content, no keyword stuffing.

## Starting semantic clusters

- ответы на отзывы маркетплейсов; автоматические ответы на отзывы; ИИ для ответов; сервис ответов на отзывы; ответы на вопросы покупателей; автоматизация поддержки продавца;
- Wildberries/WB-specific responses to reviews/questions;
- Ozon/Yandex Market/Avito-specific response intent with readiness honesty;
- единый кабинет отзывов; управление отзывами нескольких маркетплейсов; аналитика отзывов; шаблоны ответов; тональность бренда.

These are research seeds, not final keyword evidence.

## Route intent map

`/`: category + branded conversion. `/features`: capability evaluation. `/marketplaces`: coverage. Marketplace pages: channel-specific intent and readiness. `/pricing`: commercial intent. `/demo`: product demo intent. `/resources`: authority hub, not empty blog shell.

## Page brief template

Primary cluster, intent, segment, pain, mechanism, now-vs-planned status, evidence, CTA, internal links, unique metadata, structured-data eligibility and genuinely useful FAQs.

## Technical SEO

Unique titles/descriptions, canonicals, `metadataBase`, robots/sitemap, app/auth excluded from indexing, one visible h1, logical headings, descriptive links, public copy server-rendered, real OG assets only, correct status codes, no soft 404, image dimensions/compression/alt, controlled query/trailing-slash duplication.

## Canonical/schema policy

Self-canonical primary pages. Query params not new canonical pages by default. No hreflang until real alternate languages. Use structured data only when content qualifies: `WebSite`, `SoftwareApplication`, `Organization` after operator identity known, `BreadcrumbList`, selective `FAQPage`. Never invent ratings, offers, review counts, company data or awards.

## Content quality

No paragraph exists solely to repeat a keyword. No four marketplace pages created by name substitution. Explain technical mechanisms in seller language first. No fake proof.

## Required research before final rewrite

Inspect current Yandex/Google SERPs and autocomplete, analyze 30–40 relevant Russian SaaS/marketplace/reputation/support products, examine international references for IA/differentiation, cluster intent, remove irrelevant consumer-generator traffic, document evidence and collection date.

## Success metrics

Qualified organic impressions/clicks, conversion to demo/onboarding, activation, indexing errors, Core Web Vitals field data when available and expectation-mismatch queries. Traffic alone is not success.
