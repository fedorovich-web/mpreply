# MPReply 0.1.88 Pricing/Menu Visual Correction Report

Patch `0.1.88` is a focused correction after manual visual review of `0.1.87` pricing, menu and mobile screenshots.

## Scope

- Remove the first desktop/mobile navigation item `Продукт`, because it pointed to a same-page anchor rather than a separate product page.
- Remove remaining background/fill treatments from desktop navigation active and hover states.
- Keep the accepted public type scale: H1 max 58px, H2 max 48px, H3 max 28px.
- Normalize public hero/subhero lead copy to 18px.
- Rebalance pricing hero trial card and reduce the `400 автоответов` number.
- Remove the rejected decorative bottom stripe from the pricing trial card.
- Make final CTA buttons readable on blue gradient cards.
- Calm answer-pack calculator sliders and stretch the result card to match the control column height.
- Redesign the included-features block into a cleaner card + checklist composition.
- Add a mobile menu close button and lock body scroll while the menu is open.
- Adjust public copy to auto-first positioning while avoiding absolute unsupported claims such as `работает идеально`.

## Notes

Visual snapshots were not updated in this patch. Manual screenshot review is still required before approving any visual baseline.
