# Проверка правок публичного сайта и демо — 30 сентября 2026

## Что изменено

- Удалены четыре одинаковых канала контактов с одним email и завершающие CTA-баннеры возможностей, интеграций, тарифов и контактов в RU/EN. Удалены относящиеся к ним CSS-селекторы. Форма обращения с сайта сохранена.
- Иконки отзывов, вопросов и сообщений в главном блоке «Как это работает» ограничены размером своих строк. Ранее AVIF отображались в исходном размере 128×128.
- Калькуляторы тарифов используют общий токен отступов секций вместо отдельного `clamp(70px, 9vw, 130px)`.
- Рамка EN/RU в общей шапке использует единый синий токен.
- В сравнении с менеджером зарплата фиксирована: 50 000 ₽ по умолчанию, меняется только при вводе другой зарплаты пользователем. Количество обращений ограничено 3 000 в месяц. Количество менеджеров и умножение зарплаты на объём удалены. Покупка пакетов считается отдельно.
- До готовности клиентского интерфейса элементы калькуляторов отключены, чтобы введённые до подключения обработчиков данные не терялись.
- Для реально открытого демо исправлены контраст ссылки регистрации и доступ к прокручиваемой таблице с клавиатуры.

## Кабинет: отступы и переносы

- Убраны принудительные многоточия у названий покупателей, товаров, пунктов меню, заголовков KPI и открытого обращения. Длинные слова и артикулы переносятся.
- Между заголовком страницы и описанием, подписью шага и названием панели, названием товара и маркетплейсом используются общие токены отступов.
- Таблицы обзора и обращений в узкой рабочей области показывают отдельные записи с локализованными подписями полей. На телефоне видны текст, товар, время, статус и кнопка открытия обращения. Используются те же строки и данные, без отдельного мобильного списка.
- Исправлен выход скрытой подписи таблицы за пределы страницы. Заголовки карточек интеграций и статусы переносятся на отдельную строку при нехватке места.
- Экран ИИ переключается на две колонки раньше; минимальные ширины колонок больше не обрезают содержимое. Текст обращения переносится, поля textarea используют общие стили формы и фокус.
- Фильтры автоматизации на телефоне переносятся, вместо сжатия трёх надписей в одну строку. У сводки администрирования увеличены отступы между подписями и заголовками.

Восемь разделов настоящего кабинета проверены на 320, 390, 768, 1024, 1280 и 1440 px. Выход страницы по горизонтали и текст меньше 14 px отсутствуют. На телефоне проверены открытие обращения и axe. Длинные товарные названия, включая непрерывный артикул, и сводка супер администратора проверены отдельно на тестовых API-ответах; демо не получало административных прав.

## Настоящий локальный демо-кабинет

Docker на этой Windows-системе не работает. Для проверки использованы нативные бинарники PostgreSQL 18.1 и существующее Python-окружение API. Развёрнута отдельная база `mpreply_demo` на loopback-порту 55432; все миграции применены до `20260914_0015`.

API на localhost:8000 действительно создаёт сессию демо и читает четыре примера обращений из PostgreSQL. Кабинет тот же, что у обычного пользователя. Русский десктопный и английский мобильный маршруты проверены браузером без перехвата API. Изменение организации и добавление ключей возвращают 403.

Скрипт повторного запуска: `scripts/start-local-demo-api.py`. Инструкция: `docs/operations/local-demo-without-docker.md`. Проверены Ruff, синтаксис Python и повторный запуск API на существующей базе. API остаётся в процессе терминала: отдельный завершающийся процесс запуска на Windows приводил к остановке дочернего API и ошибке открытия демо.

Redis, воркер и планировщик не запущены. `/health/ready` без Redis не проходит. Этот результат подтверждает работу локального демо, не готовность всего стека на домене. Реальные ИИ-провайдеры, почта, платежи и операции маркетплейсов не вызывались.
