# MPReply 0.1.104 Runtime Certification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a remote-green release-candidate gate and safe, evidence-producing runtime certification commands for Wildberries, Yandex Market, Ozon, and Avito.

**Architecture:** Extend the existing Quality Gate to the current integration branch flow and build every production image. Extract the invariant safety/evidence mechanics from the Yandex runtime probe into one typed core while keeping provider pagination, scopes, identifiers, preflight, send, and reconciliation in four thin provider modules and four secure PowerShell wrappers.

**Tech Stack:** Python 3.13, HTTPX, pytest, Ruff, Pyright 1.1.411, PowerShell 7, GitHub Actions, Docker Compose, Next.js/Node.js 22.

## Global Constraints

- Provider certification order is Wildberries, Yandex Market, Ozon, Avito.
- Wildberries remains the primary product execution path.
- Do not claim Yandex Market, Ozon, or Avito production sending before reviewed runtime evidence exists.
- Do not call a live marketplace API from pytest, GitHub Actions, or an implementation step.
- Do not execute any live write probe without separate operator authorization and an exact disposable target.
- Never write to protected Yandex Question ID `27265525`.
- Credentials and reply text enter Python only through environment variables, never command-line arguments.
- A probe performs no automatic HTTP, broker, or application retry.
- Once a write request starts, timeout, request error, 429, 5xx, malformed success, or failed reconciliation is `AMBIGUOUS` unless postflight proves the write.
- Evidence must not contain raw credentials, full identifiers, marketplace content, reply text, raw headers, or raw bodies.
- No new dependency, database migration, version bump, deploy, merge, image push, or public capability change.
- During implementation run one RED command and one grouped GREEN command per task. Do not rerun an unchanged suite without a named reason.
- Run one full backend/frontend/container-oriented final gate after all implementation tasks settle.

```python
_AMBIGUOUS_ERROR_CODES = frozenset({
    "network_timeout",
    "network_error",
    "rate_limited",
    "marketplace_unavailable",
    "malformed_payload",
    "marketplace_malformed_response",
})
_BLOCKED_ERROR_CODES = frozenset({"invalid_credentials", "insufficient_scope", "payment_required"})


def fingerprint(value: str) -> str:
    return "sha256:" + hashlib.sha256(value.encode("utf-8")).hexdigest()[:12]


def mask_identifier(value: str) -> str:
    return f"masked:{len(value.strip())}chars"


def safe_scopes(result: AdapterResult) -> list[str]:
    if not isinstance(result.data, dict):
        return []
    raw = cast(dict[str, object], result.data).get("scopes")
    if not isinstance(raw, list):
        return []
    return sorted({scope for value in cast(list[object], raw) if (scope := str(value).strip())})


def classify_result(result: AdapterResult, *, write_started: bool) -> FinalStatus:
    if result.ok:
        return "PASS"
    code = result.error_code or "marketplace_error"
    if write_started and code in _AMBIGUOUS_ERROR_CODES:
        return "AMBIGUOUS"
    if code in _BLOCKED_ERROR_CODES:
        return "BLOCKED"
    return "FAIL"


def exit_code(status: FinalStatus) -> int:
    return {"PASS": 0, "FAIL": 2, "BLOCKED": 3, "AMBIGUOUS": 4}[status]
```

`write_report_atomic()` must serialize `dataclasses.asdict(report)` to a same-directory temporary path, scan the serialized text for each non-empty forbidden value, flush and `os.fsync()` the file, then `Path.replace()` the final path. On error it removes only its exact temporary file in `finally`.

`build_report()` accepts explicit `started_at`, `finished_at`, `git_sha`, `app_version`, provider metadata, steps, and write fields; it performs no network, filesystem, or clock access. Provider CLIs obtain Git SHA from `MPREPLY_GIT_SHA`, require a 40-character lowercase hex value, and read the version from `app.core.config.Settings().app_version` or an explicitly injected test value.

                    check=False,
